# DP-300-Azure-Database-Administrator-Associate-Guide

## How this repo is organised
- **[SYLLABUS.md](SYLLABUS.md)** — start here: every skill in the DP-300 outline (as of 27 Oct 2026) with a checkbox and links to the notes that cover it.
- **`1 - …` to `6 - …` folders** — detailed notes, one folder per Microsoft Learn learning path, one file per unit. Files marked `[NEW]` were added in Oct 2026 to cover skills the course notes missed.
- **[VERIFICATION-LOG.md](VERIFICATION-LOG.md)** — what was corrected when all notes were checked against current Microsoft docs (Oct 2026); corrected lines end with 🔄.
- **[revision/](revision)** — condensed one-file-per-path summaries for final revision.
- **[Diffrences.md](Diffrences.md)**, **[Azure SQL DMVs list.md](<Azure SQL DMVs list.md>)**, **[Questions.md](Questions.md)** — IaaS vs PaaS comparisons, DMV playbook, practice questions.
