# DP-300 Study Guide — Administering Microsoft Azure SQL Solutions

Simple notes for the **Microsoft Certified: Azure Database Administrator Associate** exam.
Read everything in **2 days (~8 hours)**, then practise MCQs.

## Exam facts (checked 29 Oct 2026)

| Item | Detail |
|------|--------|
| Exam | DP-300: Administering Microsoft Azure SQL Solutions |
| Level | Intermediate (Associate) |
| Time | 100 minutes, proctored. Some questions may be interactive (labs/drag-drop) |
| Pass mark | 700 out of 1000 |
| Retake | After 24 hours the first time, longer for later attempts |
| Renewal | Every 12 months, by a **free** online assessment on Microsoft Learn |
| Languages | English, Chinese (Simplified/Traditional), Japanese, Korean, French, German, Portuguese (Brazil), Italian, Spanish |
| Preview features | Most questions are on GA (released) features. Popular preview features can still appear |

## Latest news

- **27 Oct 2026: new English version of the exam.** The only change is minor. "Implement Always Encrypted with **VBS** enclaves" is now "Implement Always Encrypted with **secure** enclaves". Learn both kinds (VBS and Intel SGX), see [Module 2 › Encryption](<Module 2 - Implement a Secure Environment>).
- Translated versions of the exam are updated about 8 weeks after English.
- **The practice assessment has moved to AI Skills Navigator.** You must sign in there to start it.
- **DP-300 is not retiring.** DP-100 is a different exam that retired in 2026.
- Old tools that are now retired may still show up in questions. These include Data Migration Assistant (DMA), Azure Data Studio and its migration extension, and classic DMS for SQL. The notes say what replaces each one.

Each module starts with **00 - Introduction.md**. It tells you what you will learn, lists the lessons with reading times, and explains the key words.
Every lesson has the same parts: **The big idea → concepts with examples → Remember for the exam → Quick check**.
